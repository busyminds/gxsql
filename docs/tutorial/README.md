# Tutorials

Complete these guides in order if you are new to `gxsql`.

1. [Validate a Table](getting-started.md) — install `gxsql`, open a database you
   own, select a dialect, build a suite (including structural gates and
   timestamp window or freshness checks), and distinguish execution errors from
   policy failures.
2. [Use gxsql in Go Tests](testing.md) — assert on table quality with the
   `gxsqltest` helpers.

Read the [core concepts](../concepts/) for the execution model, scope trust
boundary, result retention, and operational trade-offs behind the tutorial
steps. Use the [API reference](../reference/) for signatures and every available
builder.
